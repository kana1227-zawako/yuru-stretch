\# ゆるストレッチ



\*\*今日の体に、ちょっとした運動習慣を。\*\*



運動不足が気になり始めた40代以上の方や、運動が苦手な初心者に向けた、手軽に始められるストレッチアプリです。



部位と時間を選ぶだけで、その日の気分や空き時間に合わせたストレッチを始められます。



\## 🌿 アプリはこちら



https://yuru-stretch.vercel.app/



\## 📷 画面イメージ



!\[ゆるストレッチの選択画面](screenshots/home.png)



\## 🎯 開発の目的



運動を始めたいと思っていても、「何をすればいいかわからない」「時間がない」と感じることがあります。



そこで、難しい操作や複雑な設定をなくし、部位と時間を選ぶだけで気軽にストレッチを始められるアプリを作りました。



\## ✨ 主な機能



\- \*\*部位の選択\*\*：首・肩、背中、腰、脚の4種類

\- \*\*時間の選択\*\*：3分・5分・10分

\- \*\*ストレッチ案内\*\*：動き方、実施時間、回数、注意事項を表示

\- \*\*タイマー機能\*\*：実施時間をカウント

\- \*\*操作機能\*\*：前へ・次へ・リセット・途中終了

\- \*\*合図音\*\*：ストレッチの切り替わりを音でお知らせ

\- \*\*完了画面\*\*：コース終了をお知らせ



全17種類のストレッチを収録しています。
